1. Подключить Telegram

Историю читает ваш аккаунт. Сессия хранится локально; отключить её можно здесь или в Telegram → Устройства.

Первое подключение · данные приложения Telegram

Один раз создайте приложение в my.telegram.org/apps и вставьте два значения. Это требование Telegram; экспортировать переписку не потребуется.

В Telegram откройте Настройки → Устройства → Подключить устройство и отсканируйте код.

2. Выбрать историю

Участники, которые включили участие через /roast_on. Выберите до десяти. Анализ использует до 300 последних доступных сообщений каждого участника; история загружается в пределах выбранного периода.

ИНСТРУКЦИЯ МОДЕЛИ
Как бот шутит.
Системный промпт из того же Python-модуля, который формирует запросы модели.
Следующим сообщением модель получает ContextPack: реплику, выбранные источники и контекст сессии. Личные данные запросов здесь не выводятся.
Повторный запрос после ошибки может дополняться инструкцией исправления формата.
После изменения файла перезапустите бот и админку, чтобы оба процесса загрузили новую версию.
