# Админка бота v0.2

Панель работает на aiohttp в том же event loop, что и бот. Одна очередь обслуживает прожарки, зацепки и составление профилей. Просмотр данных использует SQLite read-only snapshot; записи настроек и импорта выполняют отдельные транзакции.

## Запуск

```powershell
uv sync --frozen
uv run pozor serve
```

`BOT_TOKEN` и `ADMIN_PASSWORD` задаются в `.env` установки. Пароль — минимум 16 символов. `.env` ищется в `POZOR_HOME` или корне проекта, независимо от текущего каталога. Панель: `http://127.0.0.1:8090`.

Для режима только админки используйте `uv run pozor admin`. Он не запускается одновременно с `serve` на той же БД. Пути, порт и адрес задаются `DATABASE_PATH`, `ADMIN_PORT`, `ADMIN_HOST`; старого argparse с `--database`/`--port` больше нет. `python -m pozor.admin` сохранён только как совместимый запуск без этих аргументов.

Для модели из Compose на Windows-хосте: `LLM_BASE_URL=http://127.0.0.1:18080`. Внутри Compose приложение использует `http://llm:8080`. Сервис приложения теперь называется `app`.

## Разделы

- **Портреты:** участники с согласием, цитаты, авторы, наблюдения, зацепки и исключение зацепки из генерации. Чужие сообщения показываются отдельно и не становятся собственными фактами участника.
- **Участники:** включение/выключение участия в выбранном чате. После `/forget_me` включить новый сбор может сам участник через `/roast_on`.
- **История Telegram:** API ID/Hash, QR/2FA, выбор группы, до десяти участников и периода, импорт, проверка черновиков. Реквизиты из пульта главнее env; источник виден рядом со статусом. Сохранение профиля не включает согласие.
- **Настройки:** типизированный реестр, владельцы и источники значений, runtime-переопределения и их сброс. Секреты показываются только как «задан/не задан». Bootstrap-поля только для чтения.
- **Промпт:** тот же файл, который загружается при генерации; версия/хэш записываются в журнал. Перезапуск после правки файла не нужен.

Вход ограничен по попыткам. Изменяющие запросы требуют CSRF-токен, cookie — HttpOnly/SameSite=Strict. Для reverse proxy с TLS включите `ADMIN_SECURE_COOKIE=true`. Встроенный HTTP слушает localhost по умолчанию; наружу через TLS proxy или SSH-туннель.

Реквизиты лежат в `data/secrets.local.json`, сессия — в `data/telegram`. Старый `application.json` переносится автоматически. Файлы защищаются приватными правами/Windows ACL. Отключение аккаунта отзывает Telethon-сессию; отключение участия и забывание — отдельные действия.
