**pozor.me** — проект локального Telegram-бота для контекстной прожарки в группе. Бот должен находить относящиеся к разговору реплики и отвечать коротко и остроумно, опираясь на подтверждённые сообщения и выбранную историю человека.

> **Статус:** сейчас это спецификация, план реализации и набор исполняемых эталонных алгоритмов. Telegram-бот, его команды, база данных и интеграция с LLM ещё не реализованы. Описанные ниже команды и сценарии — проектируемый контракт, а не готовое приложение.

## Задача и границы

Первая версия рассчитана на личный запуск в нескольких небольших группах. Она должна принимать новые сообщения только из разрешённых чатов, поддерживать добровольное участие, импорт выбранной истории и генерацию ответа локальной языковой моделью. Владелец выбирает импортируемые данные; само добавление истории не включает участие в прожарке.

Прожарка ограничена короткими ответами и явными правилами остановки. Бот не должен превращать чужие шутки или заметки оператора в факты о человеке. Адреса и контакты, здоровье, сексуальная жизнь, защищённые характеристики, угрозы и выдуманные серьёзные обвинения исключаются из тем для шуток. Молчание завершает сессию и не считается признанием поражения.

В V1 не входят голосовые сообщения, OCR, распознавание изображений, веб-поиск по людям, userbot, дообучение модели, векторная база и веб-интерфейс. Для старой истории Telegram нужен экспорт, выбранный оператором: Bot API не предоставляет историю прошлых сообщений группы.

## Планируемый стек

- Python 3.12+ и aiogram 3.
- SQLite с WAL и FTS5 на локальном диске.
- Локальный llama.cpp и Qwen3-8B Q4_K_M; thinking отключён.
- Один процесс приложения и один процесс inference; без Redis и фоновых микросервисов в V1.
- Ориентир по оборудованию — одна GPU с 16 ГБ VRAM. CUDA — основной вариант для NVIDIA; Vulkan требует отдельной проверки. Скорость заранее не обещается и должна быть измерена на целевом оборудовании.

Версии зависимостей и модели предстоит зафиксировать после smoke-теста. Реальные переписки, токены и веса моделей не добавляются в репозиторий.

## Проверка эталонного кода

Для уже реализованных эталонных алгоритмов достаточно Python; сторонние пакеты не нужны:

```powershell
python -m unittest discover -s tests -v
```

Это проверяет только reference-алгоритмы. Установка и запуск бота станут возможны после реализации соответствующих пакетов плана.

## Название и команды

`pozor.me` — название проекта, а не допустимый username Telegram. Для регистрации понадобится свободное имя вида `@pozor_me_bot`, созданное через BotFather; такое имя в документации приведено как пример.

Среди проектируемых команд — `/enable_chat`, `/whois`, `/roast_on`, `/roast`, `/stop`, `/finish` и `/roast_off`. Точное поведение и разрешения описаны в [дизайне](docs/01-design.md). Пока бот не реализован, эти команды не работают.
